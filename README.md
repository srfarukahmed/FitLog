#  B14-A6-FitLog

## Project Description
FitLog is a modern and responsive workout library and fitness tracking application built to help users explore different exercises, view detailed workout information, create personal workout plans, and save their favorite workouts. The application provides a clean and user-friendly experience where users can browse workouts from an API, manage their daily workout routine, track workout statistics, and organize their fitness activities through a dedicated My Plan dashboard.


## Technologies Used

- Next.js- For building the application with modern React features and routing
- TypeScript - For type-safe and maintainable development
- Next.js App Router - For handling application routes and navigation
- Tailwind CSS - For responsive styling and modern UI design
- DaisyUI - For reusable UI components
- React Context API - For global state management of workout plans and saved workouts
- React Toastify - For displaying user notifications
- React Icons - For interface icons and button elements
- Local Storage - For saving workout plan data after page reload


##  Key Features

### 1. Workout Library

- Displays workout exercises fetched from the FitLog API.
- Responsive workout card layout.
- Shows workout image, category, equipment, duration, calories, and rating.
- Users can browse and select workouts easily.

### 2. Workout Details Page

- Provides complete information about each workout.
- Includes workout image, description, specifications, and instructions.
- Users can add workouts to today's plan or save them for later.
- Displays toast notifications after actions.

### 3. My Plan Dashboard

- Manage today's workout plan and saved workouts.
- Displays live workout statistics:
  - Total exercises
  - Total minutes
  - Total calories
- Includes options to view details, mark workouts as done, and remove workouts.

### 4. Workout Sorting System

- Allows users to sort workouts based on:
  - Duration
  - Calories
  - Rating

### 5. Responsive Design

- Fully responsive across desktop, tablet, and mobile devices.
- Optimized layouts for navbar, hero section, workout cards, details page, and dashboard.
